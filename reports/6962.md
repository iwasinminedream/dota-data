# Dota 6962: что изменилось

Отчёт создан автоматически 2026-10-19. Сводку написал Claude Haiku 4.5 по изменениям API из дампа и по .so-библиотекам (с доступом только на чтение); таблицы ниже посчитаны без модели.

## Сводка

Проанализировал файлы. Составляю отчёт:

### Главное

- **Арканум Тайдхантера** — новый арканум с система прогресса (достижения за мультигеройские Ravage и съеденную рыбу) и три стиля: "Maw of the Megalodon", "The Hammer of Maelrawn", "Unfathomable Hunger"; добавлены локализация, консольные переменные и панели HUD.
- **Система покупки персон** — добавлены 8 новых слотов одежды для эффектов способностей персоны 1-го варианта (`DOTA_LOADOUT_TYPE_ABILITY_EFFECTS_*_PERSONA_1`), метод `GetAbilityNameLocalizedForAbilityID()` в Panorama GameUI для локализации.
- **Экспорт композиций в JPEG** — добавлены методы `WriteCompositionLayerJPEG()` ко всем панелям (параллельно существующему PNG); методы `WriteCompositionLayerPNG()` изменены на два параметра вместо одного (добавлен filename).
- **Переработка войск Венома** — класс `npc_dota_venomancer_plague_ward` заменил пять отдельных уровней (1–5); удален класс `CDOTA_Ability_Aghanim_Spear` и метод `LaunchSpear()`.
- **Ресурс одежды для Дроу** — новый сет "Dread Retribution" (Sepulchral Stalker) в раздаче "Trove of Terror", добавлены варианты стилей.
- **Новые события и свойства модификаторов** — `OnDamageHPLossSelf()`, `OnTreePlanted()`, `GetModifierMinAttackRange()`, события `MODIFIER_EVENT_ON_TREE_PLANTED` и `MODIFIER_EVENT_ON_DAMAGE_HP_LOSS_SELF`, свойство `MODIFIER_PROPERTY_MIN_ATTACK_RANGE`.
- **Экспериментальные NPC контроллеры** — добавлены `dota_use_experimental_npc_controller_*` для отдельных типов юнитов (герои, крипы, питомцы, Рошан).
- **Обновление стоимости Некономикона** — все три уровня (базовый, 2, 3) дороже на +650 золота.

### Для разработчиков кастомок

**Новое в Lua API:**
- Методы модификаторов: `GetModifierMinAttackRange()`, `OnDamageHPLossSelf()`, `OnTreePlanted()`
- События: `MODIFIER_EVENT_ON_TREE_PLANTED` (410), `MODIFIER_EVENT_ON_DAMAGE_HP_LOSS_SELF` (411)
- Свойство: `MODIFIER_PROPERTY_MIN_ATTACK_RANGE` (119)

**Новое в Panorama API:**
- Метод `CDOTA_PanoramaScript_GameUI.GetAbilityNameLocalizedForAbilityID(nAbilityID)` — получить локализованное имя способности по ID
- Методы `WriteCompositionLayerJPEG(_arg_1: string, _arg_2: string, _arg_3: number, _arg_4: number)` на всех панелях (новый формат вывода)

**Изменённое в Panorama API:**
- Методы `WriteCompositionLayerPNG()` на всех панелях: добавлен второй параметр `_arg_2: string` (filename). Старые вызовы с одним параметром сломаются, нужно добавить filename.
- Методы `SpawnHeroInScenePanelByHeroId()` на `DOTAParticleScenePanel` и `DOTAScenePanel`: третий параметр изменён с `number` на `string` — может сломать код, если передавал число.

**Удалённое:**
- Класс `CDOTA_Ability_Aghanim_Spear` и метод `LaunchSpear()` — если кастомка на них опиралась, нужна переделка.

**Новое в консольных переменных:**
- `dota_tidehunter_arcana_*` — параметры аркануума (max_fish_per_game, max_ravages_per_game, min_heroes, points_per_hero)
- `dota_use_experimental_npc_controller_*` — для кастомок с NPC может понадобиться включение экспериментального контроллера вместо стандартного

**Риск совместимости:**
- Код, вызывающий `WriteCompositionLayerPNG()` с одним параметром, требует обновления на два параметра (filename).
- Код, передающий число в третий параметр `SpawnHeroInScenePanelByHeroId()`, требует передачи строки.

Чистка кода в дампе (dump-noise.md) показывает только переупорядочение номеров анимационных активностей в `cl_script_reload` — это артефакт дампера, игра не изменилась.
