### Server and engine
- **`libtier0.so`, function 0x235370 (was 190 bytes, now 179).**
  - **What the function does:** it calls an imported function (PLT stub 0x138ee0) with the arguments `(строка, 0, 0, &err)` and copies the result into `CUtlString` via 0x134a20. If the result is empty or `err != 0`, it copies the original string. It looks like a string conversion between encodings, but I did not identify the import name.
  - **What changed:** the result of this imported function used to be freed via `g_pMemAlloc->Free` (call `[rax+0x20]`, slot 4). Now `free()` (0x1410a0) is called.
  - **Who it affects and what it means:** this is an internal engine function with no direct callers in the snapshot. There is no noticeable effect for custom games and plugins.
  - **Confidence:** the code change is confirmed by the diff. The reason (a fix for an allocator mismatch or something else) cannot be determined from the data.
