# Dota 6963: что изменилось

Отчёт создан автоматически 2026-10-19. Черновик по всем изменениям (1 частей) — Claude Haiku 4.5, проверка по исходным данным и итог — Claude Opus 5.5 (оба только с правом чтения); таблицы ниже посчитаны без модели.

## Сводка

### Главное

- В этой сборке (6962 → 6963) **нет видимых изменений API**. Файл `api-changes.txt` пустой: нет новых, удалённых или изменённых функций Lua API, Panorama, событий, модификаторов или консольных переменных.
- Поменялся только машинный код двух библиотек: `libserver.so` вырос на 704 байта, `libclient.so` на 256 байт. Новых или удалённых строк и экспортов нет. Похоже на точечные правки внутри уже существующих функций (исправления, поправки логики), но что именно поменялось, по данным определить нельзя.
- Новых имён, по которым можно было бы найти изменение (строки, символы), в бинарниках нет. Поэтому новых механик, предметов, способностей или систем данные не показывают.

### Новые свойства и методы: что делают

Новых свойств, событий и методов нет. Нет новых свойств модификаторов, функций Lua API и Panorama, поведений или флагов способностей.
- **Основание:** пустой `api-changes.txt`; в `.so` строки +0 −0 и экспорт +0 −0 (`so-diff.txt`).
- **Надёжность:** высокая.

### Для разработчиков кастомок

- Ничего нового, удалённого или переименованного в API нет. Существующие аддоны по API сломаться не должны.
- **Числовые значения констант анимаций `ACT_DOTA_*` в дампе ненадёжны.** Контрольный дамп той же сборки (`dump-noise.md`) показывает, что между двумя запусками дампера сдвигаются на ±1 значения нескольких констант:
  - затронуты `ACT_DOTA_CAST3_STATUE`, `ACT_DOTA_CAST4_STATUE`, `ACT_DOTA_CHANNEL_STATUE`, `ACT_DOTA_DEFEAT_STATUE`, `ACT_DOTA_DISABLED_END`, `ACT_DOTA_CYCLONE`, `ACT_DOTA_IMPALE`, `ACT_DOTA_VOODOO_REST`, `battlemaiden_debut_truncated`;
  - в одном из двух дампов есть `ACT_DOTA_CAST5_STATUE`, а в другом вместо неё `ACT_DOTA_TORRENT`.
- **`ACT_DOTA_TORRENT`.** Поэтому в текущем дампе `dumper/dump` нет `ACT_DOTA_TORRENT`, хотя в `previous-dump.txt` она есть. Это ошибка дампера, а не удаление константы из игры.
- **Вывод для аддонов:** ссылайтесь на анимации по именам констант (`ACT_DOTA_CYCLONE` и т. п.), а не по числам, взятым из дампа.
